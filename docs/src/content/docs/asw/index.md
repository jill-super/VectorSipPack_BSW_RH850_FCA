# Application Software (ASW)

Application software layer. This SIP delivery contains no production ASW; application behaviour is demonstrated by the Demo applications.

## Why is there no ASW here?

This is a **BSW/SIP delivery**, not an application project. There is no production Application Software layer. Application-side behaviour (startup, callbacks, NV handling, CAN wakeup) is shown by the [Demo Applications](../demo/) and their `fbl_ap*` integration files.
