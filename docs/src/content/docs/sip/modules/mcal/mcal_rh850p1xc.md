# SIP: Mcal_Rh850P1xC

![Third-party](https://img.shields.io/badge/Third-party-red)

> SIP CBD1800284 view of **Mcal_Rh850P1xC** (Basic Software – MCAL). Canonical reference: [Mcal_Rh850P1xC](../../../modules/mcal/mcal_rh850p1xc/). Sources: `BSW/Mcal_Rh850P1xC/`.

## Delivery scope

Integration point for the Renesas RH850 P1x-C MCAL (ADC, DIO, FLS, MCU, PORT, SPI, WDG, GPT, ICU, PWM, ...). Only Vector .mak integration files and BSWMD references are shipped; the MCAL itself must come from Renesas. See the 3rd-party MCAL integration references.

**Origin in this delivery:** Third-party (Renesas MCAL, not delivered).
